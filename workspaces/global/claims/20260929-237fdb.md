**Claim:** Project TITAN audit 2026-09-29: the '0/40 survivors' terminal claim is an artifact of a broken measurement instrument, not a market finding. Five independently sufficient defects, each located: (1) scripts/screening/screen.py:40-61 never exits a position -> 1 trade per hypothesis, verified results.json has trades:1 in every cell, voiding the 0/15 row; (2) 'replicated' defaults False in 6 screen modules and is never True in prod -> zero survivors is a CONSTANT, not a measurement (CRYPTO-001 passed 4/5 gates, EQ-007 passed 5/9 incl OOS Sharpe 1.249); (3) validator.py:265 detects failed gates only via a string containing a cross-mark that appears exactly once in the file (the detector itself) -> EXP-00017 and EXP-00019 both committed decision:promote with failing gates; (4) FX cost constant cost_bps=10.0 labelled '~1 pip' (run_fx_experiments.py:10-11) is 10-100x too high and was used only on the failing studies, while run_traderdev_families.py:23 uses 0.9bp on the same instrument -- it killed EXP-00022 (t=2.67 over 412 weekly obs, 8 years, a published FX anomaly) at exactly 0.00% net; at 1-2bps it nets +4.4-4.9%/yr Sharpe 0.48-0.54; (5) SE(SR_ann)=sqrt((1+0.5*SR^2)/T) >= 1/sqrt(T) regardless of trade count (Lo 2002) -- T=0.41yr gives SE 1.56, T=2yr gives 0.94, so 17 of 21 results are UNDERPOWERED not refuted, and the '60 trades' gate was set for the wrong failure mode (at sigma/mu=1.5, 9 trades suffice; real trades ran sigma/mu~16). Separately: the paper runtime cannot place a single order -- bridge.py:34 default certificate_ref='dummy_cert_for_paper_session' -> engine.py:890 json.loads -> raise, and paper_session.py:914 has no try/except; the 1180-test suite is green only because tests/conftest.py:81-85 is an autouse fixture replacing submit_intent with _submit_intent_core, skipping the exact gate the runtime hits. Mutation testing (20 mutants): 8 killed, 6 survived including abs() on Sharpe, profit_factor hardcoded 100.0, drawdown sign inverted, sqrt(252)->sqrt(12), and dual_ma hardcoded long-only -- 1 test in 1180 asserts an absolute PnL. The Rust core survived everything (PnL sign-flip = 35 failures); all defects are in the Python research/runtime layers.
