**Claim:** On this host every coding agent is uid 1000 with /proc/PID/environ readable and no hidepid, so identity, leases and any in-process gate are advisory: the only thing that converts 'the brain checks you' into 'the brain cannot be forged' is a root-owned secret the agent cannot read (an ed25519 key plus a fingerprint anchor) and a privileged process that observes execution itself. Design every control against that, not against the polite case.
