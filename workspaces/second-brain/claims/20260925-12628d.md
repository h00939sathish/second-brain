**Claim:** THE DASHBOARD NEVER HAD A REACT TYPE LAYER: @types/react and @types/react-dom were absent from package.json, devDependencies AND package-lock.json, and react@19 bundles no types of its own. tsconfig.json sets no `strict`, so noImplicitAny is off and `import React from 'react'` silently became any -- every useState in all 19 .tsx files returned any. Consequence: `npm run lint` passing is NOT evidence the dashboard type-checks, and CLAUDE.md's 'npm run lint && npm run build must stay green' was satisfied against a vacuous lint. Diagnosed via ChatroomDeliberationView.tsx:425 TS2345 ('unknown' not assignable to 'string'), which was a symptom, not the bug. Fixed in the types install; the same change surfaced 3 real masked bugs in App.tsx where a prop was passed under a name the child never declared (onDeployClick/onBrandChange/onCreated vs onOpenDeployModal/onToggleBrand/onAddTask) leaving three controls inert, because onClick={undefined} does not throw. Verify with: npx tsc --noEmit && ls node_modules/@types/react. Follow-up worth considering: add "strict": true, since noImplicitAny off is what let a missing @types package go unnoticed.
